# Product Overview

## 제품

`p3-web-buyer`는 Social Seller의 구매자용 프론트엔드다. 주문제작 케이크 구매자가 스토어와 상품을 탐색하고, 상담을 통해 주문 조건을 확정한 뒤 Point3로 결제하고 주문 상태를 확인하는 흐름을 담당한다.

## 대상 사용자

- 주문제작 케이크의 디자인, 색상, 문구, 사이즈, 픽업 조건을 판매자와 상담해야 하는 구매자
- 스토어와 상품을 먼저 둘러보고 상품 문의 또는 스토어 일반 문의로 상담을 시작하려는 사용자
- 결제 완료 후 주문 진행 상태, 결제·환불 내역, 연결된 상담 기록을 확인하려는 사용자

## 핵심 가치

- 상담을 제거하지 않고 스토어 탐색, 주문서 작성, 주문확인서 확인, 결제, 주문 기록을 하나의 흐름으로 연결한다.
- 상품 문의로 시작한 상담에서는 문의 상품 카드를 유지해 사용자가 문의 맥락을 잃지 않게 한다.
- Point3 결제 성공 후 주문을 생성해 채팅 기록에만 의존하던 주문 관리 위험을 줄인다.
- 모바일 환경에서 상담, 주문서 작성, 결제와 주문 확인을 끊기지 않게 제공한다.

## 관련 시스템

- `p3-api`: 인증 동기화, 스토어·상품 조회, 문의·메시지, 주문서, 주문확인서, 결제, 주문, 알림 API
- AWS Cognito: 회원가입, 로그인, OAuth, 토큰 발급과 갱신
- Point3: 브라우저 결제창과 결제 승인 대상
- S3·Lambda 이미지 파이프라인: 스토어·상품·채팅 첨부 이미지 Delivery URL 제공
