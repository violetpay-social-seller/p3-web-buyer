# Scope

## MVP 포함

- Cognito 기반 구매자 회원가입, 통합 로그인, 로그아웃, 회원 정보 조회·수정·탈퇴
- 로그인 후 역할이 `BUYER`이면 구매자 홈으로 이동하고, 역할이 다르면 해당 도메인 또는 접근 제한 화면으로 보낸다.
- 공개 스토어 목록·검색, 스토어 상세, 스토어 상품 목록, 상품 상세 조회
- 스토어 일반 문의 시작과 상품 문의 시작
- 상품 문의 채팅방에서만 문의 상품 카드 표시
- 상담 목록, 상담 채팅방, 텍스트 메시지, 이미지 첨부, 주문서 작성·제출
- 주문확인서 조회, 수정 요청, 결제요청 카드 확인, Point3 결제 시작·실패·결과 확인
- 서버 승인 성공으로 생성된 주문 목록·상세 조회
- 주문 진행 상태 확인, 연결된 상담 이동, 주문 취소 요청
- 결제 내역과 환불 상태 확인
- 알림 목록, 읽지 않음 수, 읽음 처리, 대상 화면 이동
- 로딩, 빈 상태, 오류, 권한 없음, 차단·탈퇴·종료 상태

## MVP 제외

- 비회원 구매
- 장바구니와 바로 구매
- 재고, 품절, 생산 슬롯, 예약 가능 수량 제어
- 배송
- 예약금, 잔금, 분할 결제
- 부분 취소와 부분 환불
- 찜, 리뷰, 추천, 기획전, 인기 검색어, 최근 본 상품
- 앱 내부 아이디 찾기, 비밀번호 찾기, 비밀번호 재설정
- 판매자 스토어·상품·주문 관리 UI
- 운영 관리자 UI

## 나중에 검토

- 상담 재개 정책과 메시지 보관 기간
- 참고 이미지 개수, 형식, 용량 제한
- 상품 기본 가격과 옵션 가격의 구매자 노출 수준
- 픽업 리마인더 채널과 발송 시점
- 주문 및 상담 기록 복구
