# Project API Contract

## Purpose

이 파일은 기존 템플릿 호환용이다. 구매자 앱의 실제 도메인 계약은 아래 문서를 우선한다.

- `store-product.md`
- `inquiry-order-form.md`
- `payment-order.md`
- `auth.md`
- `user.md`
- `asset.md`
- `common-response.md`

## Rules

- 새 API를 추가할 때 임의 Mock을 먼저 만들지 않고 이 폴더의 관련 계약 파일에 URI, DTO, 오류를 기록한다.
- 구매자 API와 운영자 API를 섞지 않는다.
