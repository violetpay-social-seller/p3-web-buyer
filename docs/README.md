# p3-web-buyer Docs

`p3-web-buyer`는 `p3-api`의 구매자용 프론트엔드입니다.

## 문서 지도

- `onboarding.md`: 작업 시작 전 AI와 개발자가 읽는 순서
- `00-product/`: 제품 개요, MVP 범위, 용어
- `01-decisions/`: 기술 선택과 중요한 결정 기록
- `02-frontend/`: 프론트엔드 구현 규칙, 라우팅, 상태, API Client
- `03-design/`: 디자인 시스템, UI 규칙, 접근성, AI식 디자인 금지
- `04-screens/`: 화면별 목적, 상태, 완료 기준
- `05-api-contracts/`: `p3-api` 요청/응답 계약
- `06-runbooks/`: 로컬 실행, 환경변수, 배포, 문제 해결
- `07-work-log/`: 임시 기록, 막힌 항목, 안정화 메모

## 주요 출처

- Obsidian `04 프론트엔드`: 기술 기준, 라우팅, 화면 명세, 상태, 데이터 모델, API, 동적 폼, 컴포넌트, Mock, Figma 규칙
- Obsidian `01 기획`: 프로젝트 정의, 정책 및 기능 범위, 기능 명세, IA, 의사결정 기록, 유저 플로우

## 원칙

제품 설명, 구현 규칙, API 계약, 작업 로그를 섞지 않습니다.
영구 정책은 `07-work-log/`에 두지 말고 관련 문서나 ADR로 승격합니다.
확장 후보와 결정 필요 항목은 확정 기능처럼 구현하지 않습니다.
