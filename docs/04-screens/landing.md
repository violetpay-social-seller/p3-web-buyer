# Landing

## 목적

구매자 홈과 공개 탐색 진입점이다. 스토어 목록·검색으로 이동하고, 로그인 사용자는 상담·주문·알림·마이페이지로 이어진다.

## 접근 권한

공개 접근 가능. 문의, 주문, 결제, 알림, 마이페이지 행동은 로그인 구매자만 가능하다.

## 주요 섹션

- 공개 스토어 요약
- 스토어 검색 진입
- 상담 목록, 주문 목록, 결제 내역, 알림, 마이페이지 진입
- 비로그인 사용자의 로그인 CTA

## 사용자 액션

- 스토어 선택 후 `/stores/[slug]` 이동
- 검색 후 `/stores` 이동
- 로그인 필요한 행동 선택 시 Return URL을 보존한 인증 이동

## 데이터

`StoreSummary`, 현재 사용자 요약, 읽지 않은 알림 수

## Loading 상태

최초 스토어 요약은 Skeleton으로 표시하고, 사용자 정보 갱신은 기존 화면을 유지한다.

## Empty 상태

공개 스토어가 없으면 탐색 가능한 스토어가 없음을 안내한다.

## Error 상태

스토어 요약 실패 시 재시도와 검색 화면 이동을 제공한다.

## 구현 금지

추천, 기획전, 인기 상품, 찜, 최근 본 상품은 MVP 범위가 아니다.

## 완료 기준

모바일 360px에서 스토어 카드, 검색, 로그인 CTA가 겹치지 않는다.

## 결정 필요

홈에 어떤 스토어 정렬 기준을 사용할지 API 정책 확정이 필요하다.
