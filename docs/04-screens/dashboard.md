# Dashboard

## 목적

로그인 구매자의 상담, 주문, 결제, 알림 상태를 확인하는 개인 영역의 집약 화면으로 사용한다. 별도 대시보드 화면을 만들지 않는다면 홈 내 로그인 영역으로 흡수한다.

## 접근 권한

로그인 구매자.

## 주요 섹션

- 진행 중 상담 요약
- 진행 중 주문 요약
- 결제 결과 확인 필요 항목
- 읽지 않은 알림

## 사용자 액션

- 상담 목록과 채팅방 이동
- 주문 목록과 주문 상세 이동
- 결제 내역 이동
- 알림 대상 화면 이동

## 데이터

`InquirySummary`, `OrderSummary`, Payment 요약, Notification 요약

## Loading 상태

각 섹션은 독립 Skeleton 또는 기존 데이터 유지 갱신을 사용한다.

## Empty 상태

상담·주문·결제가 없으면 탐색 시작 행동을 제공한다.

## Error 상태

섹션별 재시도를 제공하고 전체 화면을 막지 않는다.

## 구현 금지

가짜 통계, 임의 차트, 추천 스토어 알고리즘을 만들지 않는다.

## 완료 기준

빈 계정 `buyer-new`와 정상 계정 `buyer-active` 시나리오가 모두 자연스럽게 보인다.

## 결정 필요

구매자 전용 대시보드를 별도 라우트로 둘지 홈 로그인 영역으로 둘지 확정이 필요하다.
