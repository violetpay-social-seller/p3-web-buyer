# Settings

## 목적

구매자 내 정보, 알림 설정, 로그아웃, 회원 탈퇴를 관리한다.

## 접근 권한

로그인 구매자.

## 주요 섹션

- 이름, 이메일, 역할, 상태
- 알림 수신 설정
- 마케팅 수신 설정
- 로그아웃
- 회원 탈퇴

## 사용자 액션

- 회원 정보 수정
- 알림 설정 변경
- 로그아웃 확인
- 탈퇴 안내 확인 후 탈퇴 요청

## 데이터

`CurrentUser`, 알림 설정

## Loading 상태

저장 중에는 중복 제출을 막고 기존 입력을 유지한다.

## Empty 상태

선택 알림 설정이 없으면 기본 설정만 표시한다.

## Error 상태

필드 오류, 401 재로그인, 409 최신 회원 상태 충돌을 표시한다.

## 구현 금지

비밀번호 재설정, 계정 역할 변경, 판매자 정보 관리를 만들지 않는다.

## 완료 기준

수정, 로그아웃, 탈퇴 확인 흐름이 키보드와 모바일에서 동작한다.

## 결정 필요

탈퇴 취소 또는 재가입 정책.
