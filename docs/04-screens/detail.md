# Detail

## 목적

스토어 상세, 상품 상세, 상담 채팅방, 주문 상세, 결제 상세처럼 구매자의 핵심 상세 화면에 적용할 공통 기준이다.

## 접근 권한

- 스토어·상품 상세는 공개 접근 가능
- 상담·주문·결제 상세는 소유 구매자만 접근 가능

## 주요 섹션

- 스토어 상세: 배너·프로필, 소개, 연락처·SNS, 영업시간, 상품 목록, 일반 문의
- 상품 상세: 이미지, 설명, 가격 정책, 옵션, 픽업 안내, 상품 문의
- 상담 채팅방: 스토어 헤더, 선택적 상품 카드, 메시지, 주문서, 확인서, 결제요청
- 주문 상세: 주문 스냅샷, 진행 상태, 픽업, 결제·환불, 연결 상담, 취소 요청
- 결제 상세: 결제시도, 상태, 실패 이유, 결과 확인 필요, 환불

## 사용자 액션

- 일반 문의 또는 상품 문의 시작
- 메시지·이미지 전송
- 주문서 작성·제출
- 주문확인서 확인·수정 요청
- Point3 결제 시작·재시도
- 주문 취소 요청

## 데이터

`StoreDetail`, `ProductDetail`, `InquirySummary`, `ChatMessage`, `OrderConfirmation`, `PaymentPreparation`, `OrderSummary`

## Loading 상태

상세 최초 로딩은 Skeleton, 채팅 과거 메시지 로딩은 현재 스크롤 위치를 유지한다.

## Empty 상태

상품 없음, 이미지 없음, 메시지 없음, 주문 없음, 결제 없음 상태를 구분한다.

## Error 상태

404는 목록 복귀, 403은 접근 제한, 409는 최신 데이터 재확인으로 처리한다.

## 구현 금지

상품 문의가 아닌 상담에 상품 카드를 표시하지 않는다. `POINT3_CAPTURE_READY`만으로 주문 완료를 표시하지 않는다.

## 완료 기준

일반 문의, 상품 문의, 결제 성공, 결제 실패, 결과 확인 필요, 종료된 상담 상태를 확인한다.

## 결정 필요

상품 가격 노출 수준, 참고 이미지 개수·용량, 상담 종료 후 재개 가능 여부.
