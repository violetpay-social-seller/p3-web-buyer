# AI Rules

## 반드시 지킬 것

- 작업 전 `docs/onboarding.md`, `docs/00-product/overview.md`, `docs/00-product/scope.md`, `docs/02-frontend/architecture.md`, 관련 `docs/04-screens/*.md`, 관련 `docs/05-api-contracts/*.md`를 확인한다.
- 구매자 앱 범위는 스토어 탐색, 상담, 주문서, 주문확인서, Point3 결제, 주문·결제·알림·마이페이지다.
- 상품 문의 채팅방에서만 문의 상품 카드를 표시한다. 일반 문의는 상품 카드가 없어야 한다.
- 모든 문의는 스토어에 귀속된다. 상품 카드는 소유 관계가 아니라 UX 문맥이다.
- 결제 성공 화면은 백엔드 승인 성공 결과로만 표시한다. `POINT3_CAPTURE_READY`만으로 성공 처리하지 않는다.
- 주문은 결제 성공 시 생성되며 결제 당시 스냅샷을 표시한다.
- 로딩, 빈 상태, 오류, 권한 없음, 종료된 상담, 결과 확인 필요 결제 상태를 함께 구현한다.
- API 계약이 없으면 영구 코드처럼 Mock을 만들지 말고 관련 docs에 초안 또는 결정 필요를 먼저 남긴다.

## 금지

- 비회원 구매, 장바구니, 바로 구매, 배송, 재고·품절, 예약금·잔금, 부분 환불을 구현하지 않는다.
- 판매자 관리 화면이나 운영 관리자 화면을 구매자 앱에 만들지 않는다.
- 앱 내부 아이디 찾기, 비밀번호 찾기, 비밀번호 재설정을 만들지 않는다.
- 서버 Enum 문자열을 그대로 화면에 노출하지 않는다.
- Asset ID, Object Key, 토큰, 결제 식별값을 일반 구매자 화면이나 로그에 노출하지 않는다.
- Point3 `targetOrigin="*"` 또는 Origin 검증 없는 메시지 처리를 사용하지 않는다.
