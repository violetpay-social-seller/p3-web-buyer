# p3-web-buyer 실행 방법

## 다운로드

```bash
git clone git@github.com:violetpay-social-seller/p3-web-buyer.git
cd p3-web-buyer
```

## 설치

```bash
npm install
```

## 실행

```bash
npm run dev
```

## 확인

```text
PC: http://localhost:3100
모바일: http://<내-WiFi-IP>:3100
```

## 내 WiFi IP 확인

```bash
ipconfig getifaddr en0
```
